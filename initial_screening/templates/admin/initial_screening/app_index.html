HELP

Form
A collection of questionnaires.

The form can be displayed for the clinician. It may be anonymous.

Example:

  • Post-Intervention Screening
  • Initial Screening
  • Feedback Form
Questionnaire
A page of questions.

Example:

  • DES-T
  • PCL-5

The questions always take up a page. Next page = next questionnaire.

Technically, a questionnaire is made up of question blocks, which hold questions.

Question Block
A group of Questions within a Questionnaire.

Questions are usually logically grouped.

Questions may have the same instructions.

Example: "For the next 3 questions, think about how often it has occurred in the past month."

Plain, ungrouped questions still live in one big block.
Question
A single question within a Question Block.

Stores question text, format (e.g. text, dropdown), order.

Questions may be optional.

Questionnaire Response
Records that a user submitted a response to a form/questionnaire.

See Response Item for what the user entered.
